# Extension Modules
Die **Erweiterungsmodule** bieten zusätzliche Funktionen oder erleichtern häufige Aufgaben. Wir arbeiten an einer Reihe solcher Module und stellen sie zum Testen bereit, sobald sie fertig sind. Um sie zu testen und zu nutzen, müssen Sie folgenden Bedingungen zustimmen:

  1. Für Module in der Testphase übernehmen wir keine Verantwortung. Bitte mit Bedacht einsetzen und alles sorgfältig prüfen!
  2. Fehler und Verbesserungsvorschläge bitte per E-Mail an **support-at-olex2.org** melden.
  3. Testmodule stehen zunächst 30 Tage zur Verfügung. Danach lässt sich das Modul zweimal um jeweils 30 Tage verlängern. Danach wenden Sie sich bitte an **support-at-olex2.org**, um die Module weiter zu nutzen oder zu testen.
  4. Einige dieser Module werden nach der Testphase nicht mehr kostenlos sein.

## E-Mail
Eine **gültige** E-Mail-Adresse eingeben, das gewünschte Modul im Auswahlmenü wählen und auf **Install** klicken. An diese Adresse wird eine E-Mail mit einem Aktivierungslink geschickt. **Den Link anklicken, um das Modul zu aktivieren.** Danach diesen Bereich erneut öffnen und das Modul noch einmal im Auswahlmenü wählen. Damit wird das Modul installiert; es steht **nach einem Neustart von Olex2** zur Verfügung.

## Referenz
Ein beliebiger Text, der festhält, auf welchem Rechner das Modul installiert wurde, z.B. *Mein Arbeitsrechner*.

## Module
### Liste der Erweiterungsmodule
Hier stehen alle Erweiterungsmodule, die für diese Olex2-Version (Versionsnummer sowie alpha, beta oder release) verfügbar sind. Sobald ein Modul im Auswahlmenü gewählt ist, wird aus der Schaltfläche **Please Choose** die Schaltfläche **Install**. Ein Klick darauf startet die Installation.

Hinweis: Die Liste der verfügbaren Module erscheint nur, wenn der Rechner ~online~ (mit dem Internet verbunden) ist! Offline bleibt die Liste leer!

## Offline-Installation
Ist eine Online-Installation nicht möglich, wenden Sie sich bitte direkt an **enquiries@olexsys.org**; Sie erhalten dann eine .zip-Datei mit dem gewünschten Modul. Diese Datei auf der Festplatte speichern und nach einem Klick auf "Offline installieren" diesen Speicherort angeben.
