# Tutorials-target
Einige interaktive Tutorials für den Einstieg in Olex2, im eigenen Tempo


# Tutorial header
Dieser Bereich enthält mehrere Tutorials zu den wichtigsten Funktionen von Olex2.

## QUICK DEMO
Am besten beginnt man mit dem Tutorial **QUICK DEMO**, das einen allgemeinen Überblick über Olex2 gibt.

## Basic Commands
Dieses Tutorial stellt die am häufigsten verwendeten Befehle in Olex2 vor.

## Growing
Hier geht es um die wichtigsten Wege, eine Struktur auf dem Bildschirm von der asymmetrischen Einheit bis zu gepackten 3D-Anordnungen zu vervollständigen (und diese Erweiterungen wieder rückgängig zu machen).

## Measurements
Das Tutorial **Measurements** zeigt, wie man geometrische Messungen an der Struktur vornimmt.

## Sorting
Dieses Tutorial beschreibt die verschiedenen Möglichkeiten, die Atome einer Struktur in Olex2 zu sortieren.

## Packing
Hier werden die Befehle zur Kristallpackung vorgestellt, mit denen sich intermolekulare Wechselwirkungen untersuchen lassen.

## Mapping & Masks
Olex2 bietet viele Tools für Karten und Masken; dieses Tutorial zeigt, wie man sie zur Analyse einer Struktur einsetzt.

## 3D View Tutorial
Dieses Tutorial stellt die verschiedenen Möglichkeiten vor, eine Struktur in 3D zu betrachten, mit und ohne spezielle Ausrüstung.

## Images
Olex2 kann anspruchsvolle Grafiken von Kristallstrukturen erzeugen. Dieses Tutorial stellt die Möglichkeiten zum Erstellen von Strukturbildern vor.

## Customising the GUI
Dieses Tutorial zeigt, wie man das Aussehen der Olex2-GUI an die eigenen Bedürfnisse anpasst.
