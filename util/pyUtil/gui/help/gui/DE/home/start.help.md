# Open a Structure
Olex2 liest viele kristallographische Dateiformate. Meist beginnt die Arbeit an einer Kristallstruktur mit dem Öffnen einer .ins-Datei. Normalerweise hat die Datenreduktionssoftware zusammen mit der .ins-Datei eine .hkl-Datei mit demselben Namen erzeugt. Mehr als diese beiden Dateien braucht der Datenordner für den Anfang nicht.

## Navigieren
Eine Datei über den Link **Öffnen** im Tool Start oder über **File > Open** im Menü oben in Olex2 auswählen.

## Ziehen und Ablegen
Alternativ eine erkannte Datei per Drag and Drop in Olex2 ziehen. Die Datei wird geöffnet, und ihr Ordner wird zum aktuellen Ordner.

## Befehlszeile

| `reap` | Der Befehl **reap** öffnet eine Datei über den Dateibrowser. Ihm kann auch ein Dateiname folgen, z.B. **reap sucrose.ins**. |
