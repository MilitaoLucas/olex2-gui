# history-target
Alle Verfeinerungen und
Lösungen der Struktur
sind von hier aus erreichbar.


# History
Jeder Schritt von Strukturlösung und Verfeinerung (also jeder Klick auf **Verfeinern**) wird von Olex2 automatisch in einer Verlaufsdatenbank festgehalten. Jeder farbige senkrechte Balken in diesem Diagramm steht für einen Schritt der Verfeinerung; seine Höhe zeigt den R1-Wert bei diesem Schritt. Ein Klick auf einen Balken setzt die Struktur auf den Stand dieses früheren Schritts zurück. Wird von dort aus erneut verfeinert, entsteht ein neuer Zweig im Verlauf (siehe **Verlaufsbaum** unten).

## Pfeil links
Zeigt weiter zurückliegende Schritte der Verfeinerung.

## Pfeil rechts
Zeigt neuere Schritte der Verfeinerung.

## Show All Bars
Zeigt *alle* Schritte der Verfeinerung.

## Split Display
Zeigt nur die letzten Schritte der Verfeinerung.

## Skalierung
Größere Werte bei **Skalierung** machen die Balken höher, sodass kleine Änderungen des R1-Werts zwischen den Schritten leichter zu erkennen sind.

## .ins neu laden
Lädt die ursprüngliche .ins-Datei aus dem aktuellen Arbeitsordner der Struktur neu.

## Revert HKL when reverting history
Ist dieses Feld angehakt, wird beim Zurückgehen zu einem früheren Schritt (einem Balken im Diagramm oben) auch die .hkl-Datei auf die zu diesem Schritt gehörende Version zurückgesetzt.


# History Tree
Bei jeder Strukturlösung entsteht ein neuer Zweig im Verlauf. Über das Auswahlmenü wird automatisch die neueste Struktur des gewählten Zweigs geladen. Zweige lassen sich löschen und umbenennen. Ein Klick auf den passenden Lösungs- oder Verfeinerungszweig führt zu einer früheren Strukturlösung oder zu einem ganz anderen Zweig der Verfeinerung zurück.

## Condensed
Ist dieses Feld angehakt, wird eine verkürzte Fassung des Verlaufsbaums angezeigt; sonst zeigt der Baum die Details jedes Verfeinerungsschritts.

## Auskoppeln
Öffnet den Verlaufsbaum in einem großen eigenen Fenster.
